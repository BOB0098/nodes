使用指南

三步开始

1
复制订阅链接

首页找到来源卡片，点「复制」按钮，或打开详情复制。

2
导入客户端

客户端的「配置 / 订阅」页 → 点 + → 从剪贴板导入；或在详情里用二维码扫码导入。

3
更新并连接

点这条配置的「更新」→ 选中节点 → 打开代理开关。

客户端选择

Clash 系（mihomo 内核）：Clash Verge Rev（电脑）、FlClash（手机/电脑）、Clash Meta for Android。

V2Ray 系（Xray 内核）：v2rayN（电脑）、v2rayNG（安卓）。

sing-box 系：sing-box 全平台、Hiddify（全平台）。

按首页分组选择对应协议的订阅链接，导入到匹配内核的客户端。

常见问题

复制后客户端提示导入失败？先确认客户端协议与分组一致，再从详情复制完整原始链接重试。

真实可用率是什么意思？节点经 mihomo 真实握手、拿到 204 响应才算可用，比端口可连更严格，因此数值偏低属正常。

为什么有的源节点很多但可用很少？免费源常含大量失效或被转发的旧节点，本站按真实握手统计，帮助判断实际可用性。

二维码扫不出来？链接过长时二维码可能放不下，请用「复制订阅链接」代替。

关于

项目介绍

Nodes 是一个免费节点订阅索引站，收录第三方公开发布的订阅链接，按 Clash / V2Ray / sing-box 三类分组展示，并用真实握手检测标注可用率。

数据来源与检测

来源登记于 sources.yaml，由采集程序每日自动更新，仅收录公开订阅。节点检测使用 mihomo 真实出网握手（拿到 204 才算可用），并单独统计端口连通情况。

来源评分基于真实可用率、样本量与稳定性；样本不足时标注「样本不足」，不显示稳定标签。历史趋势按实际跟踪天数展示，不足时明确说明，不伪造曲线。
