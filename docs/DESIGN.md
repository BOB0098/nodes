# Nodes UI 设计系统（P23 视觉纠偏版）

> 关键词：暖白纯色 · 墨绿强调 · 克制 · 紧凑列表主体 · 专业工具感
> 本版纠偏 P22 的灰紫偏差：紫色退为协议辅助色，列表行取代大卡片，统计压缩为单行指标条。
> 旧版规范归档：`DESIGN-p21.md`（第一代）、`DESIGN-p22.md`（灰紫第三版）。改版只动 `template.html`。

### C. 协议辅助色（仅小圆点，禁止大面积装饰）
Clash `#8B84D6` · V2Ray `#69B99A` · sing-box `#A27BD2`。
状态色：正常 `--ok` / 偏低 `--warn` / 异常 `--bad`（低饱和）。

### 深色模式
中性暖灰：`--bg:#191B1A`、`--surface:#222524`、墨绿提亮为 `#7BB99D`；详情暖深灰 `#26231F`。

### 对比度（WCAG AA 实测）
来源名 13.6:1 / 14.4:1，状态 4.6:1 / 9.7:1，详情标签 5.1:1 / 6.6:1，按钮 5.5:1 / 5.1:1。

## 2. 布局与组件

- **统计区**：单行指标条（上下一根细线分隔），16px 数字 + 11px 标签，禁大卡片。
- **订阅列表（视觉主体）**：每组一个 `--surface` 轻容器（1px 边框、12px 圆角、无阴影），行间 1px 分割线；单行两段：名称+副标签+状态+轻量图标按钮 / 节点数·真实率·更新时间。
- **行按钮**：无边框透明底、44px 触控区、18px 线性图标；不做凸起拟物。
- **分组头**：8px 协议圆点 + 标题 + 条数；内核名 11px 弱化至右端；可折叠。
- **详情弹层**：顶部名称+状态标签+简介；三格核心指标（可用节点/真实可用率/质量等级）优先；其余信息弱化在轻卡片内；长 URL `word-break:break-all`；底部三按钮统一 44px。
- **圆角**：容器 12px / 子块 10px；阴影仅 toast 与弹层投影，卡片零阴影。
- **桌面（≥1024px）**：内容列 760px 居中，列表加宽、名称列放宽；不简单拉伸。

## 3. 动效
仅页面淡入、弹层滑入、按压反馈；`prefers-reduced-motion` 全关闭；低核设备降级。

## 4. 兼容回退
底部导航先写纯色再写 `color-mix`（旧内核回退）；不使用 `light-dark()`。
