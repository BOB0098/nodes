## 5. 兼容性规避

- 底部导航 `background: color-mix()` 前加纯色回退，旧版微信/Safari 不支持 color-mix 时降级为纯色，不影响功能。
- 深浅色用 `@media (prefers-color-scheme)` 而非 `light-dark()`，兼容更广。
- `backdrop-filter` 同时写 `-webkit-` 前缀。
- 安全区用 `env(safe-area-inset-bottom, 0px)`，刘海屏不遮挡。
