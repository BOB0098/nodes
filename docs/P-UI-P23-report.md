- **第 3 轮**：完整页面复审（指南/关于/桌面数据中心/桌面首页）：均达标。记录一处可接受小项：桌面端「来源治理」统计块为全宽行（未用两列栅格），阅读无碍。
- 每轮截图保留：第 1 轮在仓库历史外仅存工作区归档（r1 前缀已归档至 `/tmp/p23-r1`），最终以 r2/r3 前缀截图入仓 `docs/ui-screenshots/`。
