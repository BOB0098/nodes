## 7. 关键设计决策

1. **窄屏统计条**选「缩字号收间距」而非「换行/隐藏」——保住单行指标条的紧凑层级，三项完整可读。
2. **桌面 tabbar 选浮动胶囊而非顶栏**——保留任务书「保留现有导航及路由行为」的最小改动，只改呈现形态，不改交互结构。
3. **≥1024px 才横向展开行内信息**——768px 平板保持移动两行式，避免中等宽度行内拥挤。
4. **灰阶加深但不改层级语言**——`--ink-3` 仍保留给内核名等「明确要求弱化」的纯辅助信息，主次层级不因可读性修正而消失。
