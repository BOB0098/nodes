# Nodes UI 设计系统（第三版 · 全面重设计）

> 关键词：极简主义 · 纯色背景 · 毛玻璃 · 轻新拟态 · 柔和光影 · 低饱和 · 手机优先
> 设计基准：本次最终确认的第三版效果图。禁止山脉/星球/气泡/风景/插画，禁止大面积渐变与光效，禁止 AI 后台模板感。
> 改造对象是 `template.html`（`index.html` 由 `collector.py --render` 生成，改 index 会被下一轮 CI 覆盖）。旧版规范归档于 `DESIGN-p21.md`。

## 2. 字体与排版

- 中文/英文/数字统一现代无衬线系统栈：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 数字 `font-variant-numeric: tabular-nums` 等宽对齐。
- 层级比例（相邻 ≥1.25x）：页面标题 22px / 分区标题 15px / 正文 14px / 辅助 12px。
- 来源名为英文项目简称 `font-weight: 650`；副标签（Reachable/Full）12px 辅助色。

## 3. 卡片与控件

- 圆角：卡片 14px、次级块 11px、按钮 11px —— 适中，不滥用胶囊，不做超大圆角白块。
- 半透明白卡 + `backdrop-filter: blur(14px)`，低透明度边框 `1px solid rgba(129,120,216,.12)`。
- 柔和双层阴影：`0 1px 2px rgba(37,37,54,.05), 0 8px 24px rgba(37,37,54,.06)`；禁止厚重黑影。
- 轻新拟态按钮：浅色实底 + 上缘高光 + 下缘柔影；`transform: translateY(1px)` 按压反馈。
- 触控区 ≥44×44px。

## 4. 动效

- 加载淡入、卡片 `rise .45s ease-out both`、弹层进出、Toast 上浮、数字 countUp。
- 克制：不连续弹跳、不大范围缩放、不影响浏览。
- `prefers-reduced-motion: reduce` 关闭全部动画；低性能设备（`hardwareConcurrency<=2` / `deviceMemory<=2`）自动降级。

## 6. 数据与业务保护

- 页面数据来自 `collector.assemble()` 注入的 `__DATA__`，UI 只读不改。
- 展示名通过前端 `URL → {name, sub, repo}` 映射表管理，不覆盖 `sources.yaml` 的 `name`，不改来源 ID / 订阅 URL。
- 详情只显示真实数据支持的字段；无历史不生成趋势、无测速不显示速度、样本不足不显示稳定标签。
- 二维码复用原内联 QR 编码器（`QR.draw`），真实编码当前订阅 URL。
- 数据中心异步读取 `data/picks.json`、`source_governance.json`、`trend.json`、`threshold_watch.json`；缺数据时明确提示，不伪造。
