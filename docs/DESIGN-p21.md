# P21 UI 重设计说明（DESIGN.md）

> 任务书 §4 要求：若不支持外部设计技能格式，把关键规则整理为项目内 DESIGN.md 直接作为执行规范。
> 本文件即 P21 的执行规范 + 低保真线框。改造对象是 `template.html`（`index.html` 由
> `collector.py --render` 从它生成，改 index.html 会被下一轮 CI 覆盖）。

## 1. 采用的规则与借鉴的技能

按任务书 §4「1 主 + 1 审查」的组合原则。本项目未安装外部 Skills（避免执行来源不明的脚本、
避免引入与现有技术栈冲突的框架），改为把规则固化在这里：

| 角色 | 参考 | 采用的具体规则 | 未安装原因 |
|---|---|---|---|
| 主设计 | Junaid-PK/frontend-design-skill（克制、反模板化） | 少即是多、渐进披露、单一强调色、朴素可信、无装饰性图表/渐变/Bento 墙 | WorkBuddy 技能格式与本项目纯静态页不同；只取工作方法，不照搬默认风格 |
| 审查 | PracticalSwan/agent-skills (frontend-design) + Emmraan (ui-ux) | WCAG 2.1 AA 对比度/焦点、移动端 360–390 优先、键盘可达、prefers-reduced-motion | 同上；用本文件清单 + 多尺寸浏览器实测替代 |

许可证核查：上述仓库均为公开设计方法论参考，本项目**未复制任何代码**，仅采用通用规则，
因此不引入许可证依赖。技术栈保持 HTML/CSS 原生 + 单文件 JS，不引入 UI 框架。

## 2. 现状审计结论（改造前）

浏览器实测 360/390/768/1024/1440 五档（截图 `docs/img/p21-before-*.png`）：

- 无横向溢出（390px：scrollWidth == clientWidth == 390），console 无错误
- 视觉已克制：light-dark() 主题、单一蓝强调色、细边框、无渐变/玻璃拟态/徽章墙/装饰图表
- 真实问题（P21 要解决）：
  1. 首屏被「订阅流程」三步教程 + 数据总览占满，主内容（源卡片列表）被推到一屏之外
  2. 无搜索；只有两个可用性开关，缺客户端格式筛选和质量排序
  3. 数据总览、地区分布、声明文字默认全展开，信息密度高
  4. 空态提示有，但缺「清除筛选」一键复位

### 桌面端（≥768px，内容限宽居中）

同样单列内容流，最大宽度沿用现有 `.wrap`（不无限拉宽）；工具栏在宽屏上：搜索框
占满主位独占一行，两个下拉并排其下，可用性开关再下一行——保持紧凑而不把控件
挤到难点的窄格。卡片保持单列（卡片内信息已足够，不塞多列）。

## 4. 设计决策

| 决策 | 理由 |
|---|---|
| 折叠「订阅流程」「数据总览」「客户端下载」为 `<details>`，默认收起 | 渐进披露：首屏只留核心状态+主操作+列表，符合「用户任务优先」 |
| 搜索按源名称/备注/URL 文本匹配 | 真实数据字段，无臆造 |
| 筛选维度=客户端格式（Clash/sing-box/v2rayNG/Hiddify/小火箭） | `it.ok` 实际是客户端适配标签，从真实卡片动态提取，绝不写死空类别 |
| 排序维度=默认（推荐优先）/ 真实可用率 / 节点条数 / 最近更新 | 全部来自真实字段 rtest/rok/count/age_h，缺失值排末尾而非当 0 |
| **不做**卡片级地区筛选 | 卡片无地区字段；地区只在总览聚合，做了就是无数据支撑的空类别 |
| **不做**单节点列表 | 本站定位是「订阅索引站」，不托管节点凭据（README 已声明）；页面展示源卡片，节点详情在订阅产物里 |
| 保留原两开关、复制/二维码/键盘操作/主题切换 | 不破坏现有能力与用户习惯 |
| 新增「清除筛选」 | 空态与筛选态都能一键复位 |
| 不引入渐变/玻璃拟态/彩色卡片墙/装饰图表/动画 | 任务书明令禁止，现状已符合，保持 |

## 5. 状态矩阵（前台必须有反馈）

| 状态 | 实现 |
|---|---|
| 首次加载 | 卡片从 `<template>` 渲染，JS 同步注入，无闪烁 |
| 加载中 | 纯静态数据，无异步请求；无需骨架（保留了空 DATA 的降级：无分组则不渲染） |
| 数据为空 | 无分组时不渲染卡片；搜索/筛选空结果 → `#fempty` 提示 + 清除筛选按钮 |
| 数据过期 | 页头 `ageH ≥ 6` 显示「已 N 小时未刷新」（已有，保留） |
| 接口失败 | 静态页无运行时接口；DATA 注入失败时整页仍可读（标题/流程/下载链接为静态 HTML） |
| 复制成功/失败 | 成功 flash「已复制 ✓」；失败 fallback 选中文本 + 提示长按手动复制（已有，保留） |
| 筛选无结果 | 提示 + 清除筛选（改） |

## 6. 无障碍验收点

- 新增 `<details><summary>` 原生可键盘展开（Enter/Space），无需额外 JS
- 搜索框 `<label>` 关联 + `aria-label`；筛选/排序 `<select>` 带 `<label>`
- 所有新增按钮 `:focus-visible` 描边；触控区 ≥44px（CSS 保证）
- `prefers-reduced-motion` 下关闭过渡（已有，扩展覆盖新增控件）
- 颜色不用作唯一信息载体（真实可用率同时有文字百分比）

## 7. 验收标准

360 / 390 / 768 / 1024 / 1440 五档：无横向溢出、console 无错误；
搜索/筛选/排序/折叠/清除/复制/二维码/主题切换交互正常截图；一致性门禁通过。
