### 关键设计决策

- **不推倒重来**：保留现有架构、URL、订阅路径、数据格式、复制/二维码/主题切换能力
- **筛选项全部来自真实数据**：客户端下拉从卡片 `it.ok` 动态提取（全部+5 个真实客户端），
  不写死空类别；排序值来自真实字段 `rtest/rok/count/age_h`
- **不做卡片级地区筛选**：卡片无地区字段，地区只在总览聚合——做了就是无数据支撑的空类别
- **不做单节点列表**：本站定位是「订阅索引站」，不托管节点凭据（README 已声明）
- **缺失值排末尾而非当 0**：排序对无真实可用率/条数/时间的源一律沉底，不伪装成 0

## 6. 未解决问题 / 已知限制

1. 客户端筛选基于源卡片的适配标签（Clash/sing-box/v2rayNG/Hiddify/小火箭），
   不是节点协议级筛选——页面不托管节点，没有协议级字段可做
2. 排序为客户端侧即时排序，刷新页面后回到「默认（推荐优先）」，不持久化用户偏好
   （刻意保持简单：无账号、无 localStorage 写入，避免状态漂移）
3. 桌面端工具栏为「搜索独占一行 + 下拉并排其下 + 开关一行」，非严格单行——
   经实测这样最紧凑且触控友好，DESIGN.md 已按实际实现描述
4. 令牌仍未撤销（按用户要求，P22 后再处理）

## 7. 回滚方式

- 页面回滚：本阶段只改 `template.html` + 重生成的 `index.html` + `data/build_manifest.json`，
  三者必须同版本回退；用 `python3 restore.py to <sha>` 回退数据后重跑
  `python3 collector.py --render && python3 build_manifest.py --write` 即可。
- 若只回退 template.html，重渲染会覆盖 index.html，不一致门禁会拦下，不会带着错位版本上线。
